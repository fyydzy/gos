## ALFWorld 实验配置和参数及在原文中的具体位置：

### 1. 数据集划分与评估指标 (Section 4.1, Page 6)

- **数据集规模**：实验在完整的 140 个 episode（回合）划分上进行评估 。  
- **指标定义**：主要评估指标为任务的平均奖励（Average reward） 。由于 ALFWorld 中的奖励是二元的，因此平均奖励等同于成功率（Success rate） 。此外，还记录了平均总 token 消耗量和仅智能体运行时间（agent-only runtime），runtime 不包含环境初始化时间 。  
- **重复实验**：每种模型与方法的组合均运行两次，最终报告两次运行的平均值 。

### 2. 对比基线 (Baselines) 配置 (Section 4.1, Page 6)

- **Vanilla Skills (原始技能基线)**：在 ALFWorld 上，Vanilla Skills 采用了官方 Agent Skills 的格式和参考库设置 。  
- **Vector Skills (向量检索基线)**：使用 `openai/text-embedding-3-large` 嵌入模型进行语义检索，维度为 3072 维 。

### 3. Graph of Skills (GoS) 配置 (Section 4.1, Page 6 & Appendix B, Page 15)

- **嵌入模型**：与 Vector Skills 一致，使用 `openai/text-embedding-3-large` 。  
- **查询重写模块**：在实验中，关闭了可选的查询重写（query-rewrite）模块，直接使用原始的任务指令作为检索查询词 。  
- **逆向图扩散权重 (Appendix B, Table 6, Page 15)**：在关系图检索的配置中，各类边缘类型向后传播的权重设定为：依赖关系（Dependency）设为 1.0，工作流（Workflow）设为 0.5，语义（Semantic）设为 0.2，替代方案（Alternative）设为 0.1 。



### 4. 评估的大语言模型 (Section 4.1, Page 6)

- 实验中统一使用了三个模型系列：**Claude Sonnet 4.5**、**MiniMax M2.7** 和 **GPT-5.2 Codex** 。



### 5. 重试策略与异常处理 (Section 4.1, Page 6)

实验采用了统一的重试策略来处理异常情况 ：  

- **环境构建失败**：如果环境构建失败，系统会重建并重新运行任务，最多额外尝试两次 。如果重试后仍然失败，这些任务将被视为未解决的基础设施故障而排除，不计入模型失败 。  
- **智能体超时 (Timeouts)**：
  - 如果智能体已经执行了很长时间后超时，记为发生实质性的执行失败，奖励记为 0，并保留在总计结果中 。  
  - 如果超时发生在建立有意义的运行之前（即启动失败），则重新运行该试验 。
- 这套重试协议同样应用于完整的 140 个 ALFWorld 评估集中 。
