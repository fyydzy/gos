### ALFWolrd

`.cache/alfworld`

`look_at_obj_in_light-AlarmClock-None-DeskLamp-323`：在台灯下看闹钟（look_at_obj_in_light），目标物 AlarmClock，灯 DeskLamp，场景 323。

#### `game.tw-pddl`

```
game.tw-pddl
├── pddl_domain    ← 定义 ALFWorld 里允许哪些动作、前提和效果
├── grammar        ← 把 PDDL 动作翻译成 Agent 能读的命令、把执行结果变成英文 Observation、开局任务描述
├── pddl_problem   ← 这一关开局存档+目标
├── solvable       ← true/false，规划器认为这关有解
└── walkthrough    ← 参考过关命令
```

#### `initial_state.pddl`

```
(define (problem plan_trial_T20190909_044715_250790)
  (:domain alfred)      ← 规则在全局 alfred.pddl
  (:objects ...)       ← 所有物体/家具实例
  (:init ...)           ← 开局事实（站在哪一个，家具的位置，是否可以用等）
  (:goal ...)           ← 过关条件
)
```

#### `traj_data.json`

```
traj_data.json
├── images           ← 192 条
├── pddl_params      ← 任务参数："object_target": "AlarmClock", "toggle_target": "DeskLamp","mrecep_target": "","object_sliced": false, "parent_target": ""
```

## 脚本

`evaluation/alfworld_run.py`：ALFWorld 文字评测入口；需环境变量 `API_KEY`、`BASE_URL`。

### 命令行参数


| 参数                         | 含义                                                                               |
| -------------------------- | -------------------------------------------------------------------------------- |
| `--model`                  | 模型名，如 `gpt-4o`                                                                   |
| `--split`                  | `dev` → `valid_seen`（ID）；`eval_out_of_distribution` → `valid_unseen`（OOD，约 85 局） |
| `--use_skill`              | 是否启用 `SkillModule`                                                               |
| `--mode`                   | `gos` / `vector` / `all_full` / `none`                                           |
| `--gos_workspace`          | GoS/vector 用的 workspace，默认 `data/gos_workspace/skills_200_v1`                    |
| `--skills_dir`             | 技能库路径，默认 `data/skillsets/skills_200`                                             |
| `--task_indices`           | 只跑指定编号，如 `0` 或 `0,2,5`                                                           |
| `--max_games`              | 在候选列表里只取前 N 局（如 `10`）                                                            |
| `--max_steps`              | 每局最多多少 LLM 回合（默认 `30`）                                                           |
| `--max_workers`            | 并行进程数                                                                            |
| `--exp_name`               | 实验名，写入结果目录                                                                       |
| `--enable_alfworld_gating` | 是否启用 ALFWorld 专用技能过滤（可选）                                                         |


结果目录：`results/alfworld/{model}/{split}_{exp_name}_mode_{mode}/idx_{游戏编号}.json`（已存在的 `idx_*.json` 会跳过）。

### 示例命令

```bash
uv run python evaluation/alfworld_run.py \
  --model gpt-4o-mini \
  --split eval_out_of_distribution \
  --use_skill \
  --mode gos \
  --gos_workspace data/gos_workspace/skills_200_v1 \
  --skills_dir data/skillsets/skills_200 \
  --max_games 10 \
  --max_workers 1 \
  --max_steps 30 \
  --exp_name eval10_gos
```
